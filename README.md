# 🧪 Ajio_Cucumber Automated Testing Project

This project is a Cucumber-based automated testing suite for the [Ajio](https://www.ajio.com/) e-commerce platform. It uses Selenium WebDriver for browser automation, TestNG for test orchestration, and follows the Page Object Model (POM) design pattern to ensure modular, scalable, and maintainable test scripts.

---

## 🚀 Project Overview

- **Application Under Test**: [Ajio](https://www.ajio.com/)
- **Testing Framework**: Cucumber with TestNG
- **Automation Tools**: Selenium WebDriver
- **Design Pattern**: Page Object Model (POM)
- **Build Tool**: Maven
- **Test Types**: Smoke and Regression

---

## ⚙️ Technologies Used

- **Java** (JDK 8+)
- **Selenium WebDriver**
- **Cucumber (BDD)**
- **TestNG**
- **Apache POI** (for reading Excel)
- **Maven**
- **Page Object Model (POM)**

---

## 📂 How to Run Tests

### 1. Prerequisites

- Java JDK installed and configured
- Maven installed
- Chrome browser installed
- ChromeDriver setup in system PATH or configured in `BrowserManager.java`

### 2. Setup

```bash
git clone https://github.com/your-username/Ajio_Cucumber.git
